# Requester
The requester is the institution requesting data from the member states, NGO’s or the industry. This usualy is more then one person. In many cases we have the somebody from the European Commission involved who deligates the dataflow execution to EEA. Inside EEA you would have a data steward who is mainly involved in the networking and oversees the dataflow implementation. A data steward is usualy supported by a data custodian who has a deep inside of the technology aspects of a dataflow process. We list a number of responsiblitiest that represents our work on Reportnet.

### Setup the dataflow inside Reportnet

This includes creating a schema and setup validation rules, test that schema and hopefully we can introduce some of the reporters into this process to provide a good structure.

### Setup custom import mechanisms

Reportnet provides some basic import methods and sometimes that isn’t enouph. Additional formats or templates can be introduced and a transformation script is build to integrate that data into Reportnet. For example an Excel template or a spatial data format such as OGC GeoPackage support.

### Setup specific manuals and how to documentation

Every dataflow has Reporting Obligation. This sometimes needs additional context on how a dataflow is reported correctly.

### Setup a Helpdesk

EEA has a generic helpdesk but usualy an additional helpdesk is required to support advice on the content inside the dataflow.
