# Reportnet platforms
### Production platforms

The production platforms are the only platforms officially available reporting platforms.

  * Production platform for Transport (<https://transport.reportnet.europa.eu>)
  * Production platform for all other dataflows (<https://reportnet.europa.eu>)

### Sandbox platform (For data stewards and data custodians)

  * The EEA Reportnet has a playground that can be used for test and experimentation (<https://sandbox.reportnet.europea.eu>)
Reportnet sandbox can only be accessed within the EEA’s firewall. This site requires that you have remote access towards the EEA. Access to this site would be by invitation. This can be the case if you are involved in new functionality on the platform or when a new data flow is developed and you are participating in the preperation.

### Test platform

  * The EEA Reportnet Testing platform (<https://test.reportnet.europa.eu>)
This is mainly used by the Reportnet developers and those who want to test new features before they are published to production.
Reportnet test platform can only be access over a VPN or from inside the EEA infrastructure.

**How to log on to the test platform**

  1. Go to https://rn3test.eionet.europa.eu/
  2. Log on by using your email.
